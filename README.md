# 好好吃飯｜一週菜單與採買

以繁體中文安排一週菜單，並自動整理採買清單的靜態網頁工具。支援桌面與手機，不需 API 金鑰或後端伺服器。

## 功能

- 27 道內建食譜，顯示份量、預估備餐時間、設備與簡單步驟。
- 七天晚餐，亦可同時規劃午餐；平日與週末可使用不同用餐人數。
- 依忌口、偏好、備餐時間和每週主食餐數安排菜單。
- 換菜選單列出所有符合條件的同類料理，可搜尋食材、設備或料理名稱，亦可依主要蛋白質篩選。
- 可任意多次指定換菜；自動挑選先輪過候選再重複，並遵循目前篩選。其餘餐點維持不變，採買清單同步重算。
- 每餐可勾選「已煮好」，採買只計算未煮餐點；取消標記會加回，狀態隨菜單保存。
- 合併同種食材、依人數換算份量，從未煮餐點需求扣除目前庫存。標記已煮好不會自動修改庫存，請填寫實際現有量。
- 分類採買、逐項勾選、複製與列印清單。
- 記錄喜好、備餐耗時與份量回饋。
- JSON 備份匯出與匯入。

## 家人使用與資料保存

GitHub Pages 網址可以直接分享給家人開啟。菜單、庫存、採買勾選與回饋只儲存在目前瀏覽器的 `localStorage`，不會上傳到 GitHub，也不會自動同步至其他裝置。若要讓家人在另一台裝置查看相同菜單，可匯出備份後在對方瀏覽器匯入。

此版本使用內建食譜庫依條件配餐，不會即時呼叫 AI API。份量與時間為食譜估算；喜好與耗時會影響後續配餐排序，份量回饋留作自行調整參考。

## GitHub Pages 部署

所有網站檔案都位於儲存庫根目錄，使用相對路徑，可部署於 GitHub Pages 專案網址。

1. 將檔案推送至 `main` 分支。
2. 在儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 分支選擇 **main**，資料夾選擇 **/ (root)**，儲存後等待發布完成。

`.nojekyll` 讓 GitHub Pages 直接提供靜態檔案，不經 Jekyll 處理。

## 開發與測試

使用純 HTML、CSS 與 JavaScript ES modules，無需安裝依賴或執行建置。透過任意靜態伺服器提供根目錄即可預覽。

```sh
npm test
node --check app.js
node --check engine.js
```

核心測試涵蓋七天／十四餐規劃、平假日份量、週三換菜後採買重算、庫存合併與單次扣抵、忌口與備餐時間、無解條件、小數精度、日期跨月跨年與輸入不可變性。

## 檔案

- `index.html`：頁面結構與操作表單。
- `styles.css`：響應式樣式。
- `app.js`：介面互動、資料保存與備份。
- `engine.js`：食譜資料、菜單產生與採買計算。
- `tests/engine.test.mjs`：核心邏輯測試。
